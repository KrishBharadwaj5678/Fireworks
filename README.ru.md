## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Fireworks.git
````

### 2️⃣ Переход в папку проекта

```bash
cd Fireworks
```

### 3️⃣ Добавление проекта в Unity Hub

- Откройте **Unity Hub**, выберите **Add** и укажите клонированную папку **Fireworks**.

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**.

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Fireworks.

## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

1️⃣ Откройте **Fireworks** и предоставьте доступ к камере для работы функций дополненной реальности.

2️⃣ Просканируйте окружающее пространство, чтобы обнаружить подходящие поверхности.

3️⃣ Нажмите на обнаруженную поверхность, чтобы разместить и запустить фейерверк.
