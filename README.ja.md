## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Fireworks.git
````

### 2️⃣ プロジェクトへ移動

```bash
cd Fireworks
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**Fireworks**フォルダを指定します。

### 4️⃣ プロジェクトを開く

- Unityによるファイルのインポートが完了したら、**Assets**フォルダからメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押してFireworksを起動します。

<img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

1️⃣ **Fireworks**を起動し、AR機能を使用するためにカメラへのアクセスを許可します。

2️⃣ 周囲をスキャンして、適切な平面を検出します。

3️⃣ 検出された平面をタップして、花火を配置・打ち上げます。
