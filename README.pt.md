## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Fireworks.git
````

### 2️⃣ Acessar o Projeto

```
cd Fireworks
```

### 3️⃣ Adicionar ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta **Fireworks** clonada.

### 4️⃣ Abrir o Projeto

- Depois que o Unity terminar de importar os arquivos, abra a cena principal na pasta **Assets**.

### 5️⃣ Executar o Projeto

- Pressione o botão **Play** no Unity Editor para iniciar o Fireworks.

<img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

1️⃣ Abra o **Fireworks** e conceda permissão para acessar a câmera e utilizar os recursos de realidade aumentada.

2️⃣ Escaneie o ambiente para detectar superfícies adequadas.

3️⃣ Toque em uma superfície detectada para posicionar e lançar os fogos de artifício.
