## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Fireworks.git
```

### 2️⃣ Navigate to the Project

```bash
cd Fireworks
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **Fireworks** folder.

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder.

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Fireworks.

## <img src="https://github.com/KrishBharadwaj5678/Fireworks/raw/main/readme/gifs/howItWorks.gif" width="35"/> How It Works 

1️⃣ Open **Fireworks** and grant camera permissions for AR functionality.

2️⃣ Scan your surroundings to detect suitable surfaces.

3️⃣ Tap on a detected surface to place and launch fireworks.
